# Workout Timer

A small interval timer for the free [Trainingym](https://www.youtube.com/channel/UCjYhS8nd7ETpwRrY69QudMg)
follow-along classes on YouTube (186 classes: toning, fat-burn, HIIT, Tabata, warm-ups, stretching…).
Each class was transcribed into its exercise sequence with work / transition / rest times, so you can run it
as a timer, read it at a glance, or build a session (warm-up → main → cool-down).

**Open it:** https://cylfox.github.io/workout-timer/

- Tabs: Workouts · Warm-ups · Cool-down & mobility · Sessions & plan
- Filters: the gear you own, fits-in time, quiet (no jumping), goal, intensity 1–5, focus
- Timer: get ready → work → rest, beeps, optional voice, "▶ watch" jumps to the exercise in the original video

Credits: class content © Trainingym (this project is not affiliated with them; it only links to their public
videos). Exercise photos from [free-exercise-db](https://github.com/yuhonas/free-exercise-db) (public domain,
Unlicense), shown only where the movement matches.
